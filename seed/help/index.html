使用帮助

Servit 是什么？

一个双击即用的本地多端口静态服务器。它解决一个问题：双击 HTML 用 file:// 打开时，Ajax 请求会被浏览器拦截。

Servit 在本地起 http:// 服务，让浏览器把页面当成正常网页，Ajax 就能发了。

多端口是什么意思？

Servit 扫描总目录下的每个一级子目录，为每个子目录单独起一个服务、单独占一个端口。根目录本身也占一个端口，并提供所有子目录的索引。

www/
├── index.html      → 8080（索引页，动态生成）
├── demo/           → 8081
├── help/           → 8082
├── proj-a/         → 8083
└── proj-b/         → 8084

怎么用？

  1. 把 servit.exe 放到任意文件夹
  2. 双击它
  3. 它会自动生成 www/、启动所有服务、打开浏览器
  4. 把你的项目丢进 www/ 下新建的文件夹里，刷新索引页即可看到

用 servit.conf 自定义

在子目录下放一个 servit.conf 文件：

title=我的项目
desc=这是一个演示页面
port=9001

索引页就会显示你写的标题和描述；port 指定后该目录固定用这个端口。三个 key 都可选。

常用参数

参数说明
-port 9000根目录端口，默认 8080，未指定端口的子目录从其后依次分配
-dir ./projects指定总目录，默认 exe 同目录的 www/
-no-open不自动打开浏览器
-spa每个单元开启 SPA 路由回退
-shutdown-timeout 10优雅退出等待秒数，默认 5
-h显示完整帮助

端口被占用怎么办？

未指定端口的单元会自动往后找可用端口。但如果 servit.conf 里显式指定了端口，被占用会报错退出——因为那是你明确指定的。

怎么退出？

在控制台按 Ctrl+C，Servit 会优雅退出：停止接受新连接，等待进行中的请求完成，然后关闭。默认最多等 5 秒，超时强制关闭。连按两次 Ctrl+C 可立即退出。

为什么需要 CORS？

如果你的页面请求的是另一个端口或域名的后端，浏览器会拦。Servit 默认给所有响应加上 Access-Control-Allow-Origin: *，省掉这部分调试麻烦。

手机能访问吗？

能。启动时控制台会打印每个单元的局域网地址。手机连同一 WiFi，浏览器打开即可。
